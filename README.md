# creativeBakery Landing Page

[Visit the Website](https://lishvets.github.io/creativeBakery) | [View Figma Design](https://www.figma.com/design/dY3izAm0Vspsmra4lQWQIP/Bakerlab_FE-students?node-id=11342-1117&p=f&t=kS6J0VnrWL7m2TMt-0)

A warm, modern, and fully responsive web platform designed for an artisanal bakery. The site allows visitors to explore various categories of freshly baked goods, get in touch with the bakers, and place custom orders online. Built with clean HTML5, modular SCSS.

## Project Overview

- **Tech Stack:** HTML5, SCSS.
- **Code Organization:** BEM methodology for scalable architecture
- **Performance & Standards:**
  - Fully validated, semantic HTML5 structure
  - Optimized media assets and inline SVG icons for quick loading
  - Flawless cross-browser compatibility with clean CSS resets
  - Responsive layout for mobile, tablet, and desktop viewports

## Development Details

- **Mobile-First Workflow:** Engineered starting from smallest screens up to high-resolution desktops to ensure optimal viewing on any device.
- **SCSS Architecture:** Utilizes nestings, custom mixins, variables, and a split-component folder structure for maintainable code.
- **Modern Layout Techniques:** Built using CSS Grid and Flexbox for stable, fluid component alignment across dynamic product catalogs.
- **Custom UI Features:** Includes styled interactive components and custom form elements tailored specifically for customer inquiries and orders.

## Features
- **Dynamic Bakery Catalog:** An organized showcase displaying various artisanal breads, pastries, and sweet treats categorized for easy browsing.
- **Mobile-Friendly Drawer Menu:** A responsive, accessible navigation drawer designed for seamless user experience on mobile devices.
- **Interactive Order & Inquiry System:** Tailored form inputs and interactive elements that allow customers to submit inquiries and place orders effortlessly.
- **Polished Visual Design:** Smooth hover interactions, subtle CSS animations, and a modern aesthetic to elevate the browsing experience.
- **Precise Layout Execution:** Clean adherence to design mockups ensuring a pixel-perfect presentation across all screens.
